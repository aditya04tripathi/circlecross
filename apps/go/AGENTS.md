# CircleCross Go application

## Overview

This Next.js application will serve people in senior school and pre university. It is a product scaffold with no product features yet.

## Commands

```bash
pnpm --filter go dev
pnpm --filter go build
pnpm --filter go lint
```

## Conventions

- Keep routes in the Next.js App Router.
- Inherit the root TypeScript, accessibility, and naming rules.

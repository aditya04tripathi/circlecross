# Administration application

## Overview

This Next.js application is the future CircleCross administration surface. It is a scaffold with no administration behaviour yet.

## Commands

```bash
pnpm --filter admin dev
pnpm --filter admin build
pnpm --filter admin lint
```

## Conventions

- Keep routes in the Next.js App Router.
- Enforce access control before adding administration capabilities.
